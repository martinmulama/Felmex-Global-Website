# Projects Page Styles

`ProjectsPage.css` is the page import index. Keep the horizontal gallery shell in `page-and-gallery.css`, the modal-style project view in `sections/project-detail.css`, and breakpoint changes in `responsive/`.

```text
styles/
├── page-and-gallery.css
├── sections/project-detail.css
└── responsive/
    ├── compact.css
    ├── mobile.css
    └── reduced-motion.css
```
