# Contact Page Styles

`ContactPage.css` is the page import index. The office selector and contact form each own their base styles, while viewport-specific rules stay in `responsive/`.

```text
styles/
├── page.css
├── sections/
│   ├── offices.css
│   └── contact-form.css
└── responsive/
    ├── desktop.css
    ├── mobile.css
    └── reduced-motion.css
```
