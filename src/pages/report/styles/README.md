# Report Page Styles

`ReportPage.css` is the page-level import index.

```text
styles/
├── page.css
├── sections/
│   ├── hero.css
│   ├── feature-grid.css
│   ├── article-rail.css
│   ├── article.css
│   └── not-found.css
└── responsive/
    ├── mobile.css
    └── reduced-motion.css
```

Keep new rules with their owning section and retain the import order in `ReportPage.css`.
